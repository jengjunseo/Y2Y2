공개 콘텐츠의 네트워크·브라우저 동작만 검사합니다. CAPTCHA, 쿠키 수집, DRM 우회는 수행하지 않습니다.

01 · BROWSER

기능 표면

저장·미디어·워커 API 존재 여부입니다. API 존재는 YouTube 바이트 접근 성공을 뜻하지 않습니다.

02 · ENDPOINT

Innertube direct POST

4개 endpoint × 최신 공개 client payload를 브라우저 origin에서 직접 호출합니다.

03 · MINIMAL SERVER

Vercel metadata resolver

같은 origin의 작은 함수가 player metadata만 요청합니다. media proxy가 아니며 cloud egress 차단을 분리합니다.

04 · OFFICIAL PLAYER

YouTube iframe

공식 embed가 로드되는지와 공개 postMessage 표면만 확인합니다. media URL/bytes는 노출하지 않습니다.

05 · GOOGLEVIDEO

Signed media URL

합법적으로 확보한 만료 전 `*.googlevideo.com/videoplayback` URL을 넣으세요.

06 · SERVICE WORKER

Opaque cache

`no-cors` 응답을 캐시할 수 있어도 JS에는 status 0, 빈 headers, null body만 보이는지 확인합니다.

07 · HLS / SABR

Manifest & UMP preflight

HLS URL은 text fetch, SABR URL은 protobuf POST 경계를 확인합니다. URL은 GoogleVideo 입력란의 값을 사용합니다.
